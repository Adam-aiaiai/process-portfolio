# RunBuddy Process Portfolio

RunBuddy Process Portfolio is a static portfolio website for the RunBuddy project, a companion-based gamified running app designed for beginner runners. The site presents the full design process, from motivation research and user requirements through ideation, implementation, evaluation, AI reflection, and references.

## Project Overview

This website is the presentation layer for the RunBuddy coursework project. It explains the problem space, shows the design journey, and documents how the concept evolved into a prototype. The content is organized as a long-form portfolio with:

- Research and motivation
- User requirements and personas
- Ideation and alternative concepts
- Technical implementation
- Evaluation and reflection
- AI reflection and tool usage
- Academic references

## Running Locally

You can open the project directly in a browser because it is a static site.

1. Clone or download the repository
2. Open `index.html` in your browser
3. Or serve the folder with any local static server

Example with VS Code Live Server:

1. Open the project folder in VS Code
2. Install the Live Server extension if needed
3. Right-click `index.html`
4. Choose `Open with Live Server`

## Deployment

Because the project is fully static, it can be deployed to:

- GitHub Pages
- Netlify
- Vercel
- Any other static hosting service

Make sure the relative paths for `css/`, `js/`, `fonts/`, and `image/` stay unchanged after deployment.

## Notes

- The project includes custom font files in the `fonts/` directory.
- The `image/` directory contains the portfolio illustrations, diagrams, screenshots, and generated assets used throughout the site.
- `index.html.bak` is a backup copy of the main HTML file.
